# 🍔 Burger Shop

Приложение для бургерной: один файл `burger-app.html`, работает офлайн, ставится на телефон как PWA.
Данные хранятся в `localStorage` браузера. Для публикации включите GitHub Pages (Settings → Pages) и откройте `index.html`.
При каждой публикации повышайте номер в `<meta name="app-version">` и в `sw.js`.
